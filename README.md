
# Python Progress Bar Simulator

## Project Description
The Python Progress Bar Simulator is an interactive
program that displays the progress of a task using
an animated progress bar in the terminal.

It allows users to enter a task name and select
a loading speed.

## Objectives
- Understand how progress bars work.
- Demonstrate loops and conditional statements.
- Display real-time progress using Python.
- Understand time delays and terminal output.

## Features
- Animated progress bar.
- Live percentage counter from 0% to 100%.
- Three loading speed options.
- Different status messages.
- Displays total completion time.
- User-friendly terminal interface.

## Technologies Used
- Python 3
- VS Code

## Python Concepts Used
- Variables
- For loops
- If-elif-else statements
- User input
- String formatting
- Time module
- Sys module

## How to Run

1. Download the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python progress_bar.py

5. Enter your task name and select a speed.

## Requirements
Python 3 must be installed.
No external libraries are required.

## Conclusion
This project demonstrates how Python can be
used to create an animated progress bar that
visually represents the completion of a task.
